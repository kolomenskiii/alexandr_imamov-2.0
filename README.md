# Александр Имамов — лендинг брокера по недвижимости

Адаптивный статический сайт на HTML, CSS и JavaScript. Исходники находятся в корне проекта. Установка npm и сборка JavaScript не нужны.

## Структура

```text
index.html                 Главная страница
privacy.html               Политика обработки персональных данных
404.html                   Страница ошибки
robots.txt                 Правила для поисковых роботов
assets/
  css/main.css             Стили, адаптивная вёрстка, палитра
  js/main.js               Меню, модальные формы, защита от отправки
  fonts/                   Локальные шрифты референса
  images/                  Портрет, свидетельство и скриншоты отзывов
  docs/                    PDF свидетельства
  icons/                   Логотип и иконки для браузеров и устройств
favicon.ico                Иконка для браузеров с поддержкой ICO
site.webmanifest           Иконки для добавления сайта на главный экран
docs/
  content-sources.md       Источники, ограничения и данные для уточнения
  form-integration.md      Порядок будущего подключения формы
scripts/
  build.py                 Подготовка публичной папки dist/
  serve.py                 Локальный сервер
ref/                       Исходные MHTML от заказчика, не публикуются
dist/                      Экспорт для хостинга, генерируется
```

## Открыть сайт

Можно открыть `index.html` в браузере напрямую. Для проверки по HTTP:

```sh
python3 scripts/serve.py
```

Адрес: http://127.0.0.1:8000. Остановка — Ctrl+C. После изменений перезапустите сервер: при старте он обновляет `dist/`. Другой порт: `python3 scripts/serve.py --port 8080`.

## Подготовить к хостингу

```sh
python3 scripts/build.py
```

На статический хостинг загружать только содержимое `dist/`. Архивы `ref/`, документы и скрипты в экспорт не попадают. Настройте хостинг на страницу `404.html` для отсутствующих адресов. Сайт не опубликован.

## Что реализовано

- Тёмная, молочная, бордовая и золотистая палитра в стиле референса.
- Один основной заголовок на раздел, без надзаголовков.
- На первом экране размещён портрет; в блоке «Индивидуальный подход» — свидетельство с возможностью открыть PDF.
- Три текстовых отзыва из сохранённого профиля Авито и тринадцать отзывов со скриншотами в адаптивном слайдере. У текстовых карточек есть ссылки на источник.
- Мобильное меню с управлением с клавиатуры, нативные раскрывающиеся ответы, якорная навигация.
- Кнопки в шапке и первом экране открывают форму с выбором задачи. Карточки продажи и покупки открывают отдельные модальные формы.
- Формы не отправляют и не сохраняют данные; кнопки отключены до подключения приёма заявок. Рабочие способы связи — телефон, Telegram и WhatsApp; кнопка MAX открывает личный профиль агента. Ссылки на Авито и Циан также доступны.
- Локальные шрифты и изображения, без внешних библиотек, аналитики и виджетов.

## Редактирование

Тексты, ссылки и поля — в `index.html`. Палитра и типографика — в начале `assets/css/main.css`. Инструкции по фотографиям находятся в `assets/images/README.md`. Сведения о происхождении контента и неопределённых данных — в `docs/content-sources.md`.
