# Изображения сайта

`aleksandr-portrait.png` используется на первом экране. `imamov-certificate.png` — превью свидетельства в блоке «Индивидуальный подход»; исходный PDF доступен по ссылке в `assets/docs/imamov-certificate.pdf`.

Скриншоты отзывов находятся в `reviews/`. При замене изображений сохраняйте осмысленные `alt`, размеры `width` и `height`, а для изображений вне первого экрана — `loading="lazy"`.
