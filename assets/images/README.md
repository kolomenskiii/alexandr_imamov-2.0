# Места для будущих фотографий

Фотографии по просьбе заказчика пока не добавлены. В HTML предусмотрены элементы `data-image-slot`:

| Слот | Содержание | Рекомендуемый исходник |
|---|---|---|
| `hero-portrait` | Главный портрет Александра | 1200 × 1500 px, WebP |
| `about-portrait` | Второй портрет / рабочая фотография | 1000 × 1200 px, WebP |

Файлы складывать в эту папку. При добавлении фото убрать `.placeholder-label`, вставить `<img>` с осмысленным `alt`, задать `width`/`height` и `object-fit: cover`. Для главного фото использовать `fetchpriority="high"`, для остальных — `loading="lazy"`. Сохранить подписи и контраст текста.
